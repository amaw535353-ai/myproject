# Verified control framework crosswalk

This is an engineering crosswalk, not a compliance claim. **Full** means the cited repository evidence directly exercises the narrow mapped control in the synthetic lab; **partial** means important production or semantic aspects remain; **gap** means no verified implementation evidence exists.
